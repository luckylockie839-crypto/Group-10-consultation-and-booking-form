# Group 10 - Consultation and Office Hour Booking Tool

Deployed link: https://luckylockie839-crypto.github.io/Group-10-consultation-and-booking-form/

Muni University, Faculty of TECHNOSCIENCE - ITM 1131 Web Application Development.

## About
This is a browser-only **demonstration** with sample staff and schedules. It does not send requests, contact staff, reserve real consultations or store data on a server. Demo bookings and reference numbers exist only in memory and are lost on reload; availability is not shared between visitors or tabs. Do not enter sensitive personal information.

## Features
- Eight sample staff members, with available and occupied sample slots
- Search by staff name, department or topic, and filter by department
- Demo form with validation, field-level errors and a local summary
- A slot is unavailable once booked in this page session or once its start time has passed; dates and times use the visitor’s local clock
- Reset clears form fields, validation errors and the form message; the last summary and demo bookings remain until reload
- Responsive layout using Flexbox and CSS Grid

## Folder structure
- `index.html` - page structure
- `style.css` - styles
- `script.js` - sample data, search, filtering and demo booking
- `muni-logo.png` - logo
- `campus.jpg` - background image

## How to run
Open `index.html` in a modern browser with JavaScript enabled. The files must remain together in the same folder. No installation or server is required.
