# Group 10 - Consultation and Office Hour Booking Tool

Muni University, Faculty of TECHNOSCIENCE - ITM 1131 Web Application Development.

## About
A browser-based tool where students can view staff consultation schedules, search for a staff member, pick a free time slot and book a consultation. All data is sample data and runs in the browser only (no database or server).

## Features
- Staff consultation schedules with available and booked slots (8 staff members)
- Search by staff name, department or topic, plus department filter
- Booking form with date, time, topic and contact details, with validation messages
- Occupied slots cannot be selected
- Booking summary with a reference number
- Empty, success and error states
- Responsive layout (mobile, tablet, desktop) using Flexbox and CSS Grid

## Folder structure
- `index.html` - page structure
- `css/style.css` - styles
- `js/script.js` - search, filtering, slot counting and booking functions
- `images/` - university logo and campus background

## How to run
Open `index.html` in any web browser.
